# Frontier map images

Both images are captures of the game renderer over the authoritative Frontier v2 voxel world (768 x 80 x 768). The lobby image `public/assets/maps/frontier.jpg` is the `vista` shot and the minimap image `public/assets/maps/frontier-overview.png` is the orthographic `overview` shot (north-up, x=0 left, z=0 top, scale 768), exported at exactly 1024 x 1024. Capture commands, budgets and the metadata contract are in `docs/maps/frontier.md`.
