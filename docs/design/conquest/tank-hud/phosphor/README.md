# Tank DRIVER view: phosphor tactical display

Feedback: "Wenn ich Panzerfahrer bin, dann möchte ich quasi dieses Zielfernrohr als eine taktische Ansicht auf dem HUD … die ganzen Stats … wie viel Ammo, welche Gun Modes … ich sag jetzt nicht Röhrenbildschirm-Style, aber so ein bisschen fluoreszierend."

Starting point: the DRIVER periscope from `../driver-view/` (variant B: brackets, heading tape, a four-cell bar in the regular HUD panel style). Its rejected variant C (a monochrome vision-TV feed) killed the team colours, so every alternative here keeps the world in colour and puts the phosphor look on the symbology.

- `phosphor-a/b/c-reference.jpg` + `.prompt.txt`: gpt-image-2 alternatives (same frame and live values: HDG 074, 23 km/h, gun 30° right, HE loading 45%, coax heat 10%, hull 640/1000, smoke ready, commander aboard).
  - A: a large glowing periscope window frame with a curved heading arc, speed and hull scales on its edges and the armament table below it. Strong "scope" feel, but the frame line runs through the world where edge-clamped flag markers live, and the console under the frame moves the minimap and squad list.
  - **B (chosen)**: the existing layout, rebuilt as a phosphor display: glowing brackets and heading tape, and one smoked-glass console at the bottom with SPEED, TURRET, ARMAMENT (all three weapons, the selected one lit, segmented load bar, coax heat, Q SWITCH) and STATUS (hull bar, smoke, commander). It shows everything asked for, leaves the window open and the minimap, squad list and markers where players know them.
  - C: two full-height data columns at the screen edges. Very readable, but it eats ~300 px of a desktop view, has no phone equivalent and pushes the minimap inward.
- `captures/hud/`: the Conquest HUD fixtures `tank-periscope`, `tank-driver`, `tank-commander` at desktop 1440×900, phone portrait 390×844 and landscape 844×390 (`node tools/conquest-hud-capture.mjs --only tank-periscope,tank-driver,tank-commander --out docs/design/conquest/tank-hud/phosphor/captures/hud`; the tool fails on any panel, button or marker overlap and passed).
- `captures/{desktop,portrait,landscape}-driver.png`: the real seat camera on the vehicle capture page (`node tools/conquest-tank-driver-capture.mjs --views driver --out docs/design/conquest/tank-hud/phosphor/captures`), AP selected and ready, gun 34° right, 23 km/h. That page has no player roster, so the commander reads `CMDR CREW`.

Compared with B: same structure (brackets, tape with the boxed heading and gun caret, four console cells with headers, inverted selected weapon row, segmented bars, crew dot). Differences: the console keeps right of the squad list, so on 1440 px it is offset right of centre and the exit prompt moves up above it; the selected weapon row is amber while the breech loads (green once ready); the world gets only a light grade plus a faint phosphor wash, scanlines, vignette and a slow refresh band instead of a tinted image, so team colours stay exact. Round counts appear only for magazine weapons: the tank's guns have none (`-1` in the snapshot), so no number is invented. Phones keep the compact console in the vehicle card's slot with AP / HE / COAX chips.
