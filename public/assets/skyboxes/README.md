# Skybox generation

Generated with the built-in ImageGen tool. Original outputs copied unchanged into this directory. The sky shader handles spherical projection, the wrap transition and poles, with procedural fallback while loading or on failure.

## voxel-daylight.png

Use case: stylized-concept. Asset type: game skybox equirectangular panorama for Voxel Blitz, a colorful blocky voxel arena FPS. Generate a single 2:1 2048x1024 full 360 by 180 degree seamless equirectangular sky texture, horizon exactly midway. Bright clean blue daylight with sculpted angular low-poly cumulus clouds, broad calm blue zenith, pale blue horizon haze. Sky only, no terrain, buildings, characters, text, borders or watermark. Restrained stylized game art, crisp faceted cloud masses, readable unobtrusive background. Left and right edges must wrap seamlessly; poles calm with no features; lower hemisphere pale blue atmospheric haze. No sun disc (engine supplies directional sun).
