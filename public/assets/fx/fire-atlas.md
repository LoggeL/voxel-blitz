# Fire atlas

Generated with the built-in imagegen tool. Consumed by ground fire and flamethrower billboard batches. Four columns and four rows, 16 row-major frames, transparent PNG. Nearest-neighbor filtering and 32-pixel cell sampling preserve the voxel style.

## Generation prompt

Use case: stylized-concept. Asset type: voxel shooter fire animation sprite atlas. Square PNG, genuine transparent alpha background. EXACTLY 4 columns by 4 rows equal cells, 16 animation frames read row-major. CHUNKY VOXEL PIXEL ART FIRE, visibly square blocks, stair-stepped angular silhouettes, like low-resolution 16x16 pixel flames enlarged with nearest-neighbor. Only 5 flat colors: dark red, red-orange, orange, yellow, pale yellow. Absolutely NO smooth curves, NO painterly texture, NO gradients, NO realistic wisps, NO glow, NO antialiasing. Each flame occupies central 70 percent of its cell with transparent margins, same baseline and consistent size. Animated looping blocky flame tongues changing subtly each frame, last frame connects to first. No ground, no labels, no grid, no checkerboard, no shadows. The sprite artwork must look built from large square pixels to fit a block-based voxel game.
